# Code-Alpha_Visualization

A comprehensive **Data Visualization project** developed using **Python**, **Pandas**, **NumPy**, **Matplotlib**, and **Seaborn**. This project generates a realistic synthetic sales dataset and creates an interactive-style business dashboard to analyze sales, profit, categories, regions, and customer segments.

---

## Project Overview

This project focuses on creating a professional **Sales and Profit Dashboard** using Python visualization libraries. The dashboard provides meaningful insights into business performance through multiple charts and graphical analysis.

The dataset is synthetically generated to simulate a real-world superstore sales environment.

---

## Project Objectives

* Generate realistic sales data using NumPy.
* Perform data aggregation and analysis.
* Visualize sales trends and profit patterns.
* Analyze customer segments and product categories.
* Compare regional performance.
* Build a professional business dashboard.
* Save the dashboard as an image file.

## Dashboard Visualizations

The dashboard contains the following visualizations:

### 1. Monthly Sales Trend

* Line chart showing monthly sales performance.
* Helps identify sales trends over time.

### 2. Sales by Segment

* Donut chart representing:

  * Consumer
  * Corporate
  * Home Office

### 3. Total Sales by Category

* Horizontal bar chart comparing:

  * Technology
  * Furniture
  * Office Supplies

### 4. Profit by Region and Category

* Grouped bar chart showing profit distribution across:

  * North
  * South
  * East
  * West

### 5. Sales vs Profit Analysis

* Scatter plot showing the relationship between sales and profit.

### 6. Top Sub-Categories by Sales

* Bar chart displaying the highest-performing sub-categories.

### 7. Sales Distribution by Region

* Box plot analyzing sales distribution and outliers.

